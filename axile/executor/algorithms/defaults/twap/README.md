# TWAP · 时间加权

按设定时长分片下单，前片欠量滚入后片。尾片可能集中补量，不保证全部成交。

## 执行方式

先按目标持仓减当前持仓得到差量，再按时间推进累计完成目标。
本片下单量＝截至本片应完成的累计量－已成交量，而不是每片机械地下相同数量。
前片欠量滚入后片，取整残差可能落到尾片；数量最终由渠道按最小下单单位处理。

适合按时间摊开委托。主动报价取对手价，被动报价取本方价，二者都可能未成交。
计划时长决定片间节奏，不是整个流程的严格墙钟截止时间；也不保证成交均价等于市场 TWAP。

## 参数

| 参数 | 默认值 | 约束 | 说明 |
|---|---|---|---|
| `total_duration` | `300` | ≥1，≤86400 | 安排拆单节奏的计划时长，不是严格截止时间。 |
| `slices` | `10` | ≥1，≤1000 | 切片间隔＝执行时长÷片数，至少 0.1 秒。 |
| `price_strategy` | `"ACTIVE"` | ACTIVE / PASSIVE | 每片使用本方价或对手价；前片欠量滚入后片。 |
| `max_wait_seconds` | `60` | ≥1，≤3600 | 实际取此值与切片间隔中的较小值。 |

## 例子

```python
algorithm = {
    "method": "TWAP",
    "params": {"total_duration": 300, "slices": 10, "price_strategy": "ACTIVE", "max_wait_seconds": 60},
}
```

计划每 30 秒推进一片，单片最多等待 `min(60, 30) = 30` 秒。
若总差量 100，第一片应累计完成 10、实际成交 6，第二片应累计完成 20，因而尝试下 14。
片间隔至少 0.1 秒；末片后不再额外等待一个完整间隔。

## 结束与剩量

切片边界响应终止请求。尾片尝试处理前序欠量，但流动性、数量取整、拒单和等待超时都可能留下剩量。
查看最终持仓与订单状态，不把切片跑完当成调仓到位。
