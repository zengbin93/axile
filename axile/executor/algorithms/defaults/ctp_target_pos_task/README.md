# TARGET-POS-TASK · 期货目标持仓

按目标净持仓安排开平仓，并按设置处理今仓、昨仓。仅用于 CTP；品种规则可覆盖报价和平仓顺序。

## 执行方式

仅用于 CTP，接收上层已经换算好的单品种目标净持仓。
增加净持仓时安排平空和剩余开多；减少净持仓时安排平多和剩余开空，并处理今昨仓。
这是下单安排顺序，不保证上一腿完全成交后才提交下一腿。

`PASSIVE` 买单取买一、卖单取卖一；`ACTIVE` 买单取卖一、卖单取买一。
所需报价不足时可能回退最新价。品种 `trade_rule.price` 优先于参数 `price_strategy`，
品种 `trade_rule.offset_priority` 优先于参数同名值。

适合需要按目标净持仓处理 CTP 开平仓的调仓。今昨顺序影响平仓安排，费用取决于具体合约，
不能笼统地认定平今或平昨一定更便宜。缺少持仓详情时可能跳过。

## 参数

| 参数 | 默认值 | 约束 | 说明 |
|---|---|---|---|
| `price_strategy` | `"PASSIVE"` | PASSIVE / ACTIVE | 本方挂单或对手价报价；品种 price 规则优先。 |
| `offset_priority` | `"昨今"` | 昨今 / 今昨 | 先平昨仓或先平今仓；品种同名规则优先，费用取决于合约。 |
| `max_wait_seconds` | `60` | ≥1，≤3600 | 等待本轮委托完成的上限，不保证持仓到位。 |
| `chase_enabled` | `false` | 见说明 | 开启后按条件撤单追价；关闭时保留下面的追单配置。 |
| `chase_ticks` | `1` | ≥0 | 触发追价的价格偏离，不是每次加价幅度。开启追单后生效。 |
| `max_chase_count` | `5` | ≥0 | 单笔委托最多追价次数。开启追单后生效。 |
| `chase_interval` | `5.0` | ≥0.0 | 两次追价的最小间隔。开启追单后生效。 |


追单关闭时仍可配置阈值、次数和间隔；关闭不会清除这些值。开启后：偏离须为 1–100 跳，
次数为 1–50，间隔为 0.1–300 秒；次数×间隔不得超过 600 秒，间隔小于 1 秒时次数不得超过 10。
这些约束不代表算法必定持续相同时间。

当前追价使用最新本方最优价（买单买一、卖单卖一），并先确认旧单已撤，再按剩余量重挂。
撤单未确认时不重复挂新单。它不是每次机械加减若干跳，也没有“超时必转市价”的保证。

## 例子

```python
algorithm = {
    "method": "TARGET-POS-TASK",
    "params": {"price_strategy": "PASSIVE", "offset_priority": "昨今", "max_wait_seconds": 60},
}
```

当前净空 3 手（昨空 2、今空 1），目标净多 2 手，需要增加净持仓 5 手。
在可平仓数量等条件满足时，安排先平昨空 2、今空 1，再开多 2；订单是否实际成交需看回报。
品种规则可覆盖上述默认报价和平仓顺序。

## 结束与剩量

等待后重新拉取账户资产，以最终净持仓是否等于目标判定达标。
委托已提交或等待已结束，都不代表最终持仓已经到位。
